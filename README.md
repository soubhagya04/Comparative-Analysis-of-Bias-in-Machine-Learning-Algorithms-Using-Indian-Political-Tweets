# Comparative-Analysis-of-Bias-in-Machine-Learning-Algorithms-Using-Indian-Political-Tweets
Machine Learning-based Political Sentiment Analysis of Indian Twitter data, focusing on BJP vs Congress. The project compares LightGBM, Logistic Regression, Linear SVM, Random Forest, and Naive Bayes using TF-IDF and SMOTE, while evaluating both classification accuracy and algorithmic fairness through F1 Gap and Cross-Party Accuracy Gap.

#SYNOPSIS
In the modern era of social media, political party leaders and supporters regularly use various platforms like Facebook and Twitter to take part in political events, campaigns, and elections. Sentiment analysis plays an important role in natural language processing and computational social science that helps analyze public opinions, emotions, and attitudes from text data. It provides valuable insights by identifying how people feel and think based on written content. Identifying political affiliation from tweets has become a significant challenge in the field of sentiment analysis and machine learning. The research problem centers on the use of political Twitter data in India to detect the political sentiments and determine whether there is an algorithmic bias in Machine Learning algorithms. With the increasing number of political content on social media, machine learning is extensively employed in sentiment analysis.
For this purpose, different supervised techniques have been used. This work analyzes the presence of bias in five machine learning algorithms like LightGBM, Logistic Regression, Linear SVM, Random Forest, and Naive Bayes. Data used for the research comprises around 79,729 tweets about BJP and Congress, two political parties in India. Given the class imbalance in the dataset, which includes more tweets about BJP than about Congress, Synthetic Minority Oversampling Technique (SMOTE) is used to obtain a balanced dataset.
The system designed utilizes an entire machine learning pipeline consisting of data acquisition, data pre processing, TF IDF feature extraction, class balance using SMOTE, training and evaluation. Several pre processing steps include lower casing, stop word removal, stemming, tokenization and noise removal for cleaning up the tweets prior to classification.
As opposed to the existing works in sentiment analysis that emphasize the accuracy of classification exclusively, this work presents fairness related measures, such as F1 Gap and Cross Party Accuracy Gap, in order to assess whether the model treats the political parties equally. In the experimental analysis, the comparative assessment is performed in terms of prediction as well as fairness. As a result, a tradeoff between accuracy and fairness is observed, since some of the presented models possess high accuracy but low bias.
